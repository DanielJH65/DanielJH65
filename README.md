## 💼 En qué trabajo

Desarrollo y mantengo sistemas de documentos tributarios electrónicos que operan en 5 países de la región, junto a un equipo de 14 personas de infraestructura, frontend, backend y DevOps. Mi trabajo reciente incluye:

- **Migración de bases de datos** de SQL Server a PostgreSQL en Aurora Serverless (más de 500 stored procedures).
- **Procesamiento asíncrono** con AWS SQS y Lambda, en reemplazo de un servicio en Windows Server.
- **Generación de reportes pesados** en contenedores Docker sobre ECS/Fargate.
- **Servicios SOAP/XML** para la integración con entidades tributarias.
